# KawaiiMD 漫游指南

> 安安静静读 Markdown——打开即读，想要即写。

本地文件夹就是它的全部：不注册账号，不建资料库，外部修改自动刷新。

## 写：左手落笔，右手成文

```ts
// ⌘S 安安静静写回原文件
const ok = await writeTextFile(path, source);
```

## 一图胜千言

```mermaid
flowchart LR
    A[双击 .md] --> B{读还是写}
    B -->|读| C[沉浸阅读]
    B -->|写| D[分栏编辑]
    D --> E[⌘S 写回]
    E --> C
```

> [!TIP]
> 把这份文档拖进 KawaiiMD，所有效果立等可看。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| ⌘E | 阅读 / 编辑切换 |
| ⌘T / ⌘W | 新建 / 关闭标签 |
| ⌘N | 新建文档 |
| ⇧⌘T | 切换亮暗主题 |

## 读：为长文而生的排版

- 亮暗双主题（墨青色板），Mermaid 图表随主题联动
- 文件树默认只显示 Markdown，目录（TOC）常伴左右
- 滚动位置记忆：切标签、外部刷新都不丢
